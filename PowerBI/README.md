# Power BI Dashboard

This section contains the Power BI dashboard developed from the processed supply chain data.

## Dashboard Overview

The five-page interactive dashboard covers:

- Procurement and collection
- Sales and revenue
- Quality and yield
- Inventory
- Finance and transportation

## Key Features

- KPI cards
- Trend analysis
- Bar charts
- Interactive slicers
- Revenue and expense analysis
- Quantity and yield analysis
- Quality acceptance analysis
- Transportation analysis
- Outstanding payment analysis

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
